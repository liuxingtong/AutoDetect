## Data


Our dataset can be found on [Hugging Face](https://huggingface.co/datasets/lrxl/AutoDetect-results).

We show data from the Autodetect process for the models listed in the paper, each in the following format:

```json
{
    "key_point": {key_point},
    "prompt": {prompt},
    "answer": {answer},
    "ref_ans": {ref_ans},
    "comparison": {comparison},
    "score": {score}
}
```
- {prompt}: The question used to evaluate the target LLM.
- {key_point}: The summary of the key knowledge encapsulated in the {prompt}.
- {answer}: The response generated by the target LLM.
- {ref_ans}: The reference response generated by GPT-4 Turbo.
- {comparison}: The comparison output from the LLM-judge (GPT-4 Turbo).
- {score}: The final evaluation score, ranging from 1 to 10.

By leveraging the `prompt` alongside the `ref_ans`, we can effectively enhance the performance of the target LLM.

## Quick Start
For all codes, we have added `#TODO` comments to indicate places in the code that need modification before running. Please update the relevant parts as noted before executing each file.



### Setup
```bash
pip install -r requirements.txt
```

### Weakness Detection (original / legacy)

The original per-domain entry points (`autodetect_if`, `autodetect_math`,
`autodetect_code`) have been moved to `legacy/`.  Each is a standalone
script with hard-coded API key and model-path placeholders.  They are
not wired into the rest of the package and are preserved here for
reference and for reproducing the original paper's exact numbers.

To run the original IF task:
```bash
cd legacy/autodetect_if/scripts
# Edit autodetect_if.py to set API_KEY, API_URL, model_path first.
bash autodetect_if
```

The result will be stored under the path
`legacy/autodetect_if/result`.

### Weakness Detection (current / small-scale reproduction)

For the current reproduction, use the unified package in
`autodetect_repro/`.  See
[`docs/reproduction_package/`](docs/reproduction_package/) for the
small-scale configs, the calibration script, and the domain-by-domain
result reports.  Quick start:

```bash
export AUTODETECT_OUTPUT_ROOT=/path/to/outputs
export SILICONFLOW_API_KEY=sk-...
python -m autodetect_repro run --live \
    --config configs/siliconflow_smallscale.yaml
```

The runner produces `samples.jsonl`, `events.jsonl`, `promoted.jsonl`,
and `report.md` in the run directory.

## SiliconFlow small-scale reproduction

This branch includes a CPU-only, API-based reproduction of AutoDetect's
instruction-following weakness-detection trend. It uses
`deepseek-ai/DeepSeek-V4-Flash` for the AutoDetect roles and judge,
`Qwen/Qwen2.5-7B-Instruct` as the target, 60 planned initial samples, and an
80-sample hard cap.

See [the runbook](docs/siliconflow-reproduction-runbook.md) for offline tests,
dry-run, smoke, live run, resume, and report commands. See
[the pitfall log](docs/reproduction-pitfalls.md) for observed setup/API issues
and code-inspection findings. Credentials are loaded from an external
environment file and must never be committed.
